# Maze Solver Using BFS and Genetic Algorithm

## Project Overview

This project explores two different approaches to solving a maze: **Breadth-First Search (BFS)** and a **Genetic Algorithm**. Both approaches were used to solve the same maze problem and explore different problem-solving strategies.

## Technologies Used

- Python
- Jupyter Notebook
- Breadth-First Search (BFS)
- Genetic Algorithm
- Maze Visualization

## Algorithms

### 1. Breadth-First Search (BFS)

BFS explores the maze level by level to find a path from the starting point to the goal.

### 2. Genetic Algorithm

A Genetic Algorithm uses concepts inspired by natural selection to search for a solution by evolving a population of candidate solutions.

## Project Goals

- Solve the same maze problem using two different algorithms.
- Explore search and optimization approaches.
- Visualize the maze and the solving process.
- Compare the approaches used by both algorithms.

## Teamwork and Contributions

This was a collaborative university project developed by a team of three students.

- **Maze Visualization:** Independently implemented the visualization component to display the maze and support the visualization of the solving process.
- **Genetic Algorithm:** Collaborated with the team on the Genetic Algorithm implementation.
- **BFS:** Used as a second approach to solve the same maze problem.

## Project Files

- **Jupyter Notebook (`.ipynb`):** Contains the project code and implementation.
